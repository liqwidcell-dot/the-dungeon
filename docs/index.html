How to Join the Server

1. Connect

Join 132.145.101.60:25565 on Minecraft Java Edition (Paper 1.21+)

2. Form a Party

Use /dungeon invite <player> to invite up to 3 others (max 4 total)

3. Start the Run

Use /dungeon to enter the dungeon. Fight through 10 waves and defeat the Dungeon Lord!
